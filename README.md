# Card Generator

A desktop application for creating, organising, and exporting custom card games.

![Card Generator](https://github.com/user-attachments/assets/35e39f0a-7435-4b48-bd5f-a7c1b226ac07)

## Features

https://github.com/user-attachments/assets/b87b1d83-b07e-4577-bbc0-f1df53c6cd61

- Create decks
- Add cards with pictures and flavour text
- Export the decks to a PDF file for printing

## Future Improvements

The initial idea was to take this concept into a cloud application, and allow users to create rooms where they can play the game (by choosing their cards at random). In future I would also include AI generation for pictures, based on flavour text, or vice versa, flavour text based on picture.

Will update this repo as I complete this future work.
